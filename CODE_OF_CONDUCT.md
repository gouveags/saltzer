# Code of conduct

Saltzer is built to serve people. Contributors must treat one another with
dignity, patience, and honesty. Harassment, demeaning conduct, threats, and
discrimination are not accepted in project spaces.

Disagreement about product or code should stay specific, evidence-based, and
charitable. Maintainers may remove content or participation that violates these
expectations. Private concerns can be raised through the repository security
contact until a dedicated conduct address is published.
