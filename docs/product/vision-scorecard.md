# Vision scorecard

Saltzer is **44% of the complete founding vision** as of 2026-08-03. This is a
product-and-business score, not a count of implemented screens. A polished local
application cannot score 100 while real customer value, retention, payments,
distribution, integrations, and behavior-driven improvement remain unproven.

The rubric comes from the two founding conversations:

- [Saltzer Product Overview](https://chatgpt.com/share/6a702b32-9810-83e9-9b6b-765c7070092e)
- [Startup Idea Compilation](https://chatgpt.com/share/6a70a37b-2cf4-83e9-a540-0c7e7b04eb28)

## Gates to 100

The next meaningful gates are deliberately outcome-based:

1. **50% — calendar-realistic mornings.** Read-only Google Calendar context turns
   available time into an inspectable suggestion that the user confirms.
2. **60% — useful AI execution.** A provider-neutral assistant can draft or
   advance one chosen outcome with visible context, approval, and result capture.
3. **72% — source-connected context.** GitHub plus one communication source can
   assemble useful context packets without becoming a generic integration hub.
4. **82% — behavior improves tomorrow.** Repeated intention-to-outcome history
   produces explainable, user-correctable planning guidance and measurably better
   completion or deliberate-release decisions.
5. **90% — trusted production product.** Hosted operations, recovery, rate
   limiting, telemetry, native releases, privacy controls, migration, and billing
   are proven.
6. **100% — the whole vision works in the world.** Paying users repeatedly choose
   Saltzer for healthy daily execution, retention and acquisition are real, and
   the product sustains its open-source mission profitably.

The percentage changes only when a gate has current evidence. Features that add
surface area without strengthening the founding loop do not move it.
